# AWS Cloud Architecting - Hands-on Labs

Hands-on labs from the AWS Academy Cloud Architecting course. Each folder contains the lab implementation: services used, what was built, technical decisions made, and problems encountered along the way.

## Labs

| Lab | Description |
|---|---|
| [S3 Static Website Hosting](./s3-static-website-hosting) | Static website on S3 with versioning, lifecycle rules, and cross-region replication |
| [IAM Policies and Roles for S3 Access](./iam-policies-s3-access) | Exploring identity-based policies, role trust policies, and S3 bucket policies |
| [Inventory Manager Production Architecture](./inventory-manager-aws-architecture) | Multi-tier stock-control web application architecture on AWS |

More labs will be added here as they're completed.
